How the two sites relate

This repository carries more than one generation of the same project, built by different sessions against the same five products. The live shop front is published from the root build. This register is the independent second check: it was produced from a separate set of source observations, and it gates its own output on a checker that fails the build if a product link is unsponsored, a claim cites a source that is not registered, or a page loses its disclosure.

Where the two agree, the agreement is evidence. Where they differ, the difference is on Flagged for Review. Four sessions independently resolved the same five links to the same five ASINs and all four report no visible tag parameter, which is why FLG-003 is stated with confidence and its compliance status is still left unresolved.
