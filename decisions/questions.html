Compliance

Q-01

Is shopnow047c-20 an approved Associates storefront, and is the account in good standing?

owner only
Already known
The tag was supplied in the brief. S01 and S02 set out what an approved account is and what happens to links that are not properly tagged.
Still missing
Whether the account exists, is approved, and is current. This is knowable only from inside the account.
What it blocks
Every product link. No link should go live until this is answered.
Cheapest way to close it
Associates Central → Account Settings → confirm the storefront ID. If the account is not yet approved, apply first and leave the site's buy buttons in their current no-tag state.

Effort: 2 minutes  ·  Sources: S01 S02  ·  FLG-001

Q-02

Are the five supplied link.amazon links compliant Special Links for this account?

requiresPurchaseOrTest
Already known
All five were opened once. None carried a visible tag parameter. All five resolved to an ASIN different from the code in the URL.
Still missing
Whether link.amazon is an Amazon-sanctioned shortener for Associates links in the owner's region, and whether these five carry a hidden tag. Neither can be settled from the redirect alone.
What it blocks
Replacing the placeholder links with live ones at scale.
Cheapest way to close it
Run the one-link enrollment test in link-audit.json. Generate one SiteStripe link, click it once, and confirm the click appears in the tracking report. If it does, generate the other four the same way.

Effort: 1 hour, no spend  ·  Sources: S01 S02  ·  FLG-003

Q-03

Where exactly does the disclosure have to sit to satisfy both Amazon and the FTC, and is once per page enough?

answerable from documents
Already known
S01 Section 5 names the sentence. S05 says a disclosure behind a click or at the end of a page is likely to be missed, and that disclosures must be hard to miss.
Still missing
Nothing material. This is answerable from the two documents and has been implemented as a strip under the masthead plus a footer repeat on every page.
What it blocks
Nothing — this one is settled.
Cheapest way to close it
Already resolved. See the compliance page for the resulting rule set.

Effort: done  ·  Sources: S01 S05

Q-12

Does the privacy page need to name every third party that sets anything?

answerable from documents
Already known
S02 Participation Requirements 3(e) requires accurate disclosure of cookies, pixels and third-party technologies, through a privacy policy or otherwise.
Still missing
The final list of third parties, which depends on Q-05 and Q-10. As built, the site sets no cookies and loads no third-party script.
What it blocks
The accuracy of the privacy page once analytics is switched on.
Cheapest way to close it
Re-read the privacy page the day analytics is enabled. It currently states the zero-third-party position, which is true today and will stop being true the moment an analytics product is added.

Effort: 30 minutes at switch-on  ·  Sources: S02

Q-15

What happens to the site if the account is terminated?

answerable from documents
Already known
S01 Section 6 allows termination on written notice with a 7-day effective date, and treats a Section 5 violation as a material breach.
Still missing
An operational plan. If the account ends, every tagged link and every display of Amazon content must stop.
What it blocks
Nothing now. It is the failure plan.
Cheapest way to close it
Documented on the Compliance page as a one-step kill switch: the site has a single link-configuration point, so removing the tag and the Amazon-derived content is one file change.

Effort: done  ·  Sources: S01

Editorial

Q-04

Can this site publish buying advice for products nobody here has handled?

owner only
Already known
S05 forbids describing experience with a product you have not tried. It does not forbid publishing factual comparisons of documented specifications.
Still missing
Whether the owner intends to fund physical testing, and whether the site should stay a listing-and-documentation desk or become a test lab.
What it blocks
The entire editorial voice, and whether the site can ever claim first-hand experience.
Cheapest way to close it
A decision, not a lookup. Pick between Path A and Path B on the Suggestions page.

Effort: 1 decision  ·  Sources: S05  ·  FLG-006

Q-06

Is the product set meant to be five air-fryer-cooking items, or is a thermometer a misfit?

owner only
Already known
Three air fryers and two thermometers. Both thermometers list air fryer among their uses. That is a defensible editorial spine: fryer plus the tool that tells you when the food is done.
Still missing
Whether the owner intends to add more thermometers (making a category) or more fryers (making a single-category site with an accessory shelf).
What it blocks
Site taxonomy and where the next ten products go.
Cheapest way to close it
Owner decision. The site currently ships the two-category structure, which works either way.

Effort: 1 decision  ·  Sources: none

Q-13

Should the site show prices at all, and if so, how?

owner only
Already known
S02 permits price display only when Amazon serves it or when it comes from Creators API / PA API with a timestamp and the required disclaimer. Static prices copied by hand satisfy neither route.
Still missing
Whether the owner has or will request Creators API access, or is willing to use SiteStripe widgets.
What it blocks
Any price comparison feature, and any article whose value depends on price.
Cheapest way to close it
Apply for Creators API access inside Associates Central, or use SiteStripe native widgets, which serve the data themselves.

Effort: application wait  ·  Sources: S02  ·  FLG-004

Q-20

Is the five-product set stable enough to design around?

requiresPurchaseOrTest
Already known
Five ASINs are recorded with an observation date. ASINs may be stored indefinitely under S02 IP License 2(h); the listing content attached to them may not be cached.
Still missing
Whether any of the five is being discontinued. A dead ASIN on a live page is a broken recommendation.
What it blocks
Whether to build comparison pages that depend on all five.
Cheapest way to close it
Check for the availability statement on each page monthly, and re-check before any campaign that spends money.

Effort: 10 minutes per month  ·  Sources: S02  ·  FLG-007

Measurement

Q-05

Where does event data go, and who is allowed to receive it?

owner only
Already known
The site records five defined events with no cookie and no identifier. A collection endpoint has to exist somewhere for that to be a measurement rather than a log line.
Still missing
Whether the owner will host an endpoint, use a hosted analytics product, or stay with browser-local counts. Each has a different disclosure obligation under S02 Participation Requirements 3(e).
What it blocks
Any statement about traffic or clicks, and the choice of next article.
Cheapest way to close it
Choose one of the three on the Metrics page. The page documents what each choice obliges you to disclose.

Effort: 1 decision, 1 hour to implement  ·  Sources: S02  ·  FLG-010

Brand

Q-07

Is The Crisp Kitchen a name the owner wants to keep, and is it clear of Amazon marks?

requiresPurchaseOrTest
Already known
S02 Participation Requirements 1(g) and Trademark Guidelines 8 forbid Amazon marks or confusingly similar names in a domain, subdomain, tag, username or app name.
Still missing
Whether the owner will register a domain, and whether a trademark search has been run on the working name.
What it blocks
Domain registration, social handles, and the final masthead.
Cheapest way to close it
Run a USPTO word-mark search on the chosen name and a domain availability check. Neither was done here, because the build must not imply a legal clearance it did not perform.

Effort: 1 hour  ·  Sources: S02

Q-17

Should each product have its own page, or is a category grid enough?

requiresPurchaseOrTest

Still missing
Whether one page per product adds enough unique information to be worth indexing, or whether it would be thin content behind five near-identical templates.

Data

Q-14

How often should the product table be re-checked, and by what mechanism?

owner only
Already known
Listings change. Every row carries an observed date of 2026-11-20.
Still missing
Whether to automate the re-check. Automation is constrained: S02 forbids data-mining and robots, and the Agent Terms require any agent to identify itself in the user agent string.
What it blocks
Whether the table can be trusted after a month.
Cheapest way to close it
Either re-check manually monthly, or obtain API access and let the API serve the data. Crawling is not an option.
