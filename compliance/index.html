The gate, in operational terms

Automated — fails the build

  • Any product anchor missing rel="sponsored".
  • Any internal link missing rel="sponsored" when it should not have it.
  • Any claim citing a source id that is not in the register.
  • Any internal link or asset that does not resolve to a file.
  • Any page missing the masthead disclosure or the footer disclosure.

Human — cannot be automated

  • Whether a factual claim is accurate. A model can check that a label exists; it cannot know the listing changed.
  • Whether a certification is real. That needs a registry lookup with a person reading it.
  • Whether the disclosure is genuinely prominent on a phone, which needs eyes.
  • Whether the account is approved, which needs the owner's sign-in.

The split matters: automating the left column is genuine progress, and pretending the right column is automated is how sites publish confidence they have not earned.

If the account is terminated

Under S01 Section 6 termination takes effect 7 calendar days after written notice, and a violation of the disclosure section is treated as a material breach. The operational consequence is simple because the site has one link configuration point: remove the tag from the link helper, remove the Amazon-derived product claims, and leave the guides — which are original writing and reference no Amazon content — in place.

That is not legal advice. It is the reason the build keeps Amazon-derived content in a single data file instead of scattered through the page templates.
