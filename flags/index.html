Official sources behind these flags

  • Amazon Associates Program Operating Agreement — current terms; re-read before campaigns.
  • Amazon Associates Program Policies — read 2026-11-20; page states “Updated: April 14, 2026”. Covers Special Links, disclosure, and content rules.
  • Amazon: ASIN definition — “a unique 10-character alphanumeric code assigned to every product listed in the Amazon store.”
  • Google: qualify outbound links — rel="sponsored" for paid/affiliate links; read 2026-11-20.
  • FTC: Endorsement Guides FAQ — includes “What About Affiliate or Network Marketing?”; read 2026-11-20.
  • FTC: Disclosures 101 for Social Media Influencers — clear-and-conspicuous disclosure baseline.
Policy re-read schedule (proposed, SG/…Q10). Monthly, and before any paid or seasonal campaign. The Associates Policies page above is the controlling text; this site’s gate encodes only mechanical checks (placement, rel, tags, links) — human review of endorsement context stays a manual step.
