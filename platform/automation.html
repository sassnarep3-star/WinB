System · Automation

Automate the arithmetic, gate the judgement

The brief asked for automation and for verified data. Those pull in opposite directions: the fastest automation is bulk extraction, and bulk extraction is exactly what the Associates licence forbids. This page states the line and why it sits where it does.

The pipeline, as built

  1. Supplied link → observed target. Each supplied link is opened once and the redirect recorded. The ASIN is read from the destination. This is manual by design.
  2. Observed target → product register. The ASIN, brand, title and category path are written to a JSON file with a date. ASINs may be stored indefinitely; listing text may not be cached, so nothing else is copied.
  3. Register → labelled claims. Strengths are labelled as seller claims and trade-offs as editorial inference. The build will not accept a claim without a label.
  4. Claims → pages. Templates render the pages, adding the disclosure, the navigation and the footer from one shared layout.
  5. Pages → gate. The checker verifies every internal link resolves, every product anchor is sponsored, every cited source exists, and every page has both disclosures.
  6. Gate → publish. Only a passing build is pushed.

Where a human has to stand

StepWhy it cannot be automatedWhat a person does
Confirming the accountRequires a signed-in session that a build must never hold.Signs in, reads the storefront ID, confirms it.
Confirming a click trackedRequires reading the Associates report after a real click.Clicks once, reads the report.
Checking a certificationNeeds a registry lookup and judgement about whether a match is the same model.Looks it up, records the certificate number or its absence.
Deciding a claim is fairA label can be checked mechanically; whether a sentence is misleading cannot.Reads the sentence as a buyer would.
Choosing the next topicRequires reading event data in context.Reads the week's events, picks.

The rule that makes this honest

Automation is allowed to check a human decision. It is never allowed to make one and present it as checked. That single rule is why the site has a build that fails on a missing source id, and no scraper.

What would unlock more automation

  • Product Advertising API access — turns price, availability and images into served data with the required timestamp, and would retire FLG-004 entirely.
  • A collection endpoint — turns the five client-side events into something that can be read a week later.
  • An identified agent — the licence permits agent access only for an agent that identifies itself in the user agent string. A compliant, self-identifying re-check job is possible; a disguised crawler is not.
