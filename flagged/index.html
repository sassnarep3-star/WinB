FLG-001

Associates enrollment for tag shopnow047c-20 is unconfirmed

Blocking Compliance Open
Expected
An approved Associates account whose storefront ID is shopnow047c-20.
Observed
The tag was supplied in the build brief. Nothing in this environment can confirm that the account exists, is approved, or owns this tag.
Why it matters
Links carrying a tag that is not enrolled earn nothing, and a Site that displays Associates links without an approved account is outside the program (S02 Participation Requirements 1).
How to close it
Sign in to Associates Central, open Account Settings, and confirm the storefront ID reads shopnow047c-20.
What it blocks
All outbound product links

FLG-003

None of the five supplied short links carried a visible Associates tag, and none resolved to the ASIN its code appears to spell

Material Link integrity Open
Expected
A Special Link carries the Associates tag as a URL parameter (S02 Participation Requirements 2(b), S01 Section 1).
Observed
For all five supplied links the resolved URL carried page-context parameters only, with no tag parameter. In all five cases the supplied code and the resolved ASIN differ, for example B04G1MEwY resolved to B0CDY277D3. Four separate agent sessions in this repository resolved the same five links independently on 2026-11-20 and reached the same two results: identical ASINs, and no visible tag.
Why it matters
If untagged, clicks cannot be attributed and no commission accrues. Separately, a code that looks like an ASIN but resolves elsewhere is exactly the failure mode a product-intent record is meant to catch.
Not claimed
This file does not assert that the links are invalid or that using them breaches the Operating Agreement. Their compliance status is unresolved. The observation is limited to what the redirect did on 2026-11-20.
How to close it
Run the enrollment test in link-audit.json: generate one SiteStripe link, publish it, click it once, and confirm the click in the tracking report before scaling to the other four.
What it blocks
Scaling from one test link to five live links

Sources: S01 S02  ·  Open the official page →

FLG-004

No price or star rating is published anywhere on this site

By design Data integrity Accepted
Expected
Prices and ratings are useful to a buyer.
Observed
The retrieved product pages mix the viewed product's price with prices for recommended products in the same text, so a single figure could not be attributed with confidence. Separately, S02 Participation Requirements 2(b) permits showing price and availability only when Amazon serves the data or it arrives via Creators API / PA API with a date stamp and the required disclaimer.
Why it matters
Publishing a price copied from a static page is both unreliable and outside the permitted methods. Publishing a rating that belongs to a different product would be the exact misleading-claim failure S02 prohibits.
How to close it
Either enable SiteStripe-served pricing widgets, or obtain Creators API access, then publish price with the timestamp and the required disclaimer text.
What it blocks
Price comparison features; does not block the shop

FLG-005

Manufacturer certifications cited in two listings were not checked against the certifying bodies

Material Product claims Open
Expected
A listing's NIST/NSF and accuracy claims can be checked against a public certification registry.
Observed
The ThermoMaven listing claims ±0.5°F accuracy and NIST and NSF certification. The CHEF iQ listing claims 1000°F heat safety. These are reproduced on the site only as seller claims, never as tested facts, because the certifying bodies' registries were not consulted.
Why it matters
S05 says you cannot make up claims about a product that would require proof. Repeating a seller's certification claim as if it were independently verified is the same error with an extra step.
How to close it
Look up the model in the NSF product listing database and in NIST's calibration program records; record the certificate or the absence of one.
What it blocks
Any page that would rank these two products on accuracy

Sources: S05  ·  Open the official page →

FLG-006

No product in this set has been physically handled by the publisher

Material Editorial integrity Open
Expected
First-hand testing before a recommendation is framed as experience.
Observed
Nothing in this environment can operate an air fryer. All strengths on the site are labelled as listing claims and all trade-offs are labelled as editorial inference from the listing, not as measurements.
Why it matters
S05 is explicit that you cannot talk about your experience with a product you have not tried. The site therefore never describes first-hand use of any product.
How to close it
Buy or borrow one unit, run a documented protocol, and publish the protocol and results. Until then the labels stay.
What it blocks
First-person review content; does not block listing-based guides
