How to use this page

Pick a row from Part one. If it is marked "Owner only", it needs the account. If it is blocked, follow the question ID in Part two before deciding. If the answer to a question turns out to be "no", the proposal usually stays a proposal — that is a valid outcome and is recorded in its "Do not choose it if" line.

Nothing here is a commitment. The site does not implement a proposal because it is on this page; it implements one when somebody reads it, decides, and changes the build. What is already built is labelled "Built", and the previous queue is preserved in the Decision Room so the reasoning behind an older choice is still readable.

What this page deliberately does not do

It does not score the proposals. A score would imply that "conversion" and "trust" can be traded on one axis, and they cannot. It also does not predict revenue: no campaign has run, so any number would be invented.
