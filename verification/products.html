Why three fields are empty

FieldReason it is not publishedWhat would let it be published
priceS02 Participation Requirements 2(b) allows a Site to show price and availability only if Amazon serves that data in the link, or if it is obtained via Creators API / PA API with the required date stamp and disclaimer. Static HTML prices copied from a product page satisfy neither condition.No price is published anywhere on this site. Each buy button says the price is shown on Amazon.
star ratingRatings are Amazon-served content. They also cannot be reliably attributed from the retrieved page text, which interleaves ratings for recommended products with the viewed product.No rating is published. Ratings are left blank rather than guessed.
product photographyS02 IP License 2(h) forbids storing or caching Product Advertising Content that consists of an image. A GitHub Pages site is a cache by definition.No Amazon product image is used. Product cards use generated editorial illustration instead, plus the plain product name.

All three reasons trace to S02 (Product Advertising Content rules and the pricing permission) and S05 (claims that require proof).

Observation method

Each supplied short link was opened once and redirected to a public Amazon product detail page. The ASIN, page title, brand and category breadcrumb recorded below were read from that page. No Amazon page was scraped at scale and no Amazon images were downloaded or cached, because S02 IP License 2(h) forbids caching images and forbids data-mining/robots, and the Agent Terms require agent traffic to identify itself.
