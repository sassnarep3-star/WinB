Suggestions for review—not automatic changes

  1. Verify catalog first. Confirm listing identity, tracking, and program eligibility for each link; hold any unresolved link.
  2. Build useful comparisons. Gather official specs/manuals and a repeatable evaluation rubric before naming winners. Use dated sources.
  3. Run an editorial pilot. Publish the four question-shaped guides as hypotheses, then review search queries and reader feedback before expanding clusters.
  4. Measure with safeguards. Add a self-hosted, privacy-preserving click counter only after an endpoint, retention policy, and privacy notice are defined. Obtain conversion figures only from authorized first-party Associates reports.
  5. Keep a campaign ledger. Start empty; record timestamp, source, channel, eligible sessions, clicks, reported orders and source provenance only when actually reported. No conversion score or revenue forecast is shown.
  6. Review before publishing. Make disclosure, link attributes, product facts, and policy checks explicit release gates.

Measurement & automation status

Not implemented: click event ingestion and self-hosted analytics endpoint. GitHub Pages serves static files; a durable endpoint requires separate hosting and privacy/retention decisions. A frontend counter alone would not be trustworthy analytics. Conversion reporting must come from authorized first-party program reports; this site does not claim access to Amazon conversion data.

Defined event plan: page_view, outbound_click, guide_engaged, disclosure_view, affiliate_conversion_reported. The last event is entered only from a dated authorized report, never inferred from a click.

Disclosure & policy gates

The disclosure is visible beneath the masthead on every page and repeated in the footer. Before adding product links, review current official program terms and applicable endorsement guidance. Every outbound product link should carry rel="sponsored" (and appropriate safety attributes), with clear context and no unsupported endorsement.

  • Amazon Associates Program Operating Agreement — official Amazon program source; review current version and applicable marketplace terms.
  • Amazon Associates Program Policies — official Amazon source; check current link, content, and disclosure requirements.
  • FTC: Endorsement Guides, What People Are Asking — official U.S. Federal Trade Commission guidance.
  • FTC: Disclosures 101 for Social Media Influencers — official FTC disclosure resource.

These are review starting points, not legal advice or a claim of completed compliance review.
