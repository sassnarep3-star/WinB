Product-intent confirmation record

Intent and observation, kept separate.

For each submitted link we store the intended ASIN, official listing URL, confirmation date and source — blank until the owner confirms. The observed redirect target is a separate measurement and the two are never merged.

Why this matters: Amazon defines an ASIN as a 10-character identifier. A 9-character short-link token is not an ASIN, and nothing public binds a short code to a product without following the redirect — so intent is confirmed by the owner, not assumed.
