Privacy and measurement

What this site records, what it does not, and why there is nothing to consent to yet.

The short version

  • This site’s own code sets no cookies.
  • It loads no third-party scripts — no analytics vendor, no advertising network, no font CDN.
  • It records five events (listed below) in your browser, and sends them to an endpoint only if one is configured. At present none is, so nothing leaves your browser.
  • It stores two keys in your browser’s localStorage: a counter of events seen, and your opt-out flag.
  • Clicking an Amazon link takes you to Amazon, which has its own privacy notice and its own cookies. That is outside this site’s control.

FTC/Amazon notice requirement

Amazon’s Program Policies require a site to disclose, accurately and adequately, the use of cookies, pixels and other technologies, and how visitor data is collected, used and disclosed. This page is that disclosure. Amazon and other third parties may set cookies when you visit Amazon after clicking a link here; this site cannot control those cookies and does not receive the data they collect.

The five events

Exactly five event names. None carries an identifier, an IP address or a fingerprint.
EventFields
page_viewpath, referrer host (if present), viewport class
product_viewproduct id, ASIN, referring page
outbound_clickproduct id, ASIN, page, position on page
guide_completeguide id, path
capture_intentpage, form id

What an event does not contain

No IP address is stored by the recorder. No cookie is created. No device fingerprint is computed. No cross-site identifier is attached. No email address is transmitted — the capture form explicitly does not send one, because no list provider exists yet. Each event carries a random value generated in memory for the current page load, which exists only so a server can discard a duplicate; it is not written to storage and it dies with the tab.

Your two controls

Turn measurement off. Click here or use “Turn off measurement” in the footer. The recorder checks the flag before it does anything and stops. Your browser keeps only the flag.

Delete what exists. Clearing site data for this domain removes the event counter and the opt-out flag.

What this means for the numbers on this site

Because measurement can be switched off and because no endpoint is deployed, this site cannot claim a traffic figure. It does not. The campaign ledger in the Data Room is empty and stays empty until an authorised first-party report provides real rows. A conversion rate computed from this site’s own counter would be a guess dressed as a statistic, and is deliberately not computed anywhere.

Children

This site is not directed at children and does not knowingly collect information from them. Amazon’s suitability rules also exclude sites directed toward children under 13 from the Associates Program, which this site is not.
